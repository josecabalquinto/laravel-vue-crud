# 📌 Laravel Vue CRUD

A simple full-stack CRUD app using **Laravel 11** for the backend and **Vue 3 Composition API** for the frontend.

---

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/your-username/laravel-vue-crud.git
cd laravel-vue-crud

### 2️⃣ Create a Database

Open phpMyAdmin (or any MySQL client)

Create a new database (e.g. laravel_vue_crud)

### 3️⃣ Configure Environment

Open the .env file

Update the following values:

DB_DATABASE=laravel_vue_crud
DB_USERNAME=your_username
DB_PASSWORD=your_password

### 4️⃣ Install PHP Dependencies
composer install

### 5️⃣ Install JavaScript Dependencies
npm install

### 6️⃣ Run Database Migrations
php artisan migrate

### 7️⃣ Seed the Database (Optional)
php artisan db:seed

### 8️⃣ Start Laravel Server
php artisan serve

### 9️⃣ Run Vite Dev Server
npm run dev


### ✅ Visit http://localhost:8000
 and enjoy your fully functional CRUD app! 🎉

🛠 Tech Stack

Backend: Laravel 11 (REST API)

Frontend: Vue 3 (Composition API)

Database: MySQL
